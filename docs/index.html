Why DESIGN:OS Code2Flow, compared with alternatives

What this project does that alternative approaches do not, or do differently. Our advantages first, followed by the honest trade-offs.

7-framework AST & route extraction

Statically analyzes Next.js App Router, React Router (v6/v7), TanStack, Expo, SwiftUI, Flutter, and Jetpack Compose into a canonical flow graph.

11-heuristic UX gap detection

Automatically flags dead-end screens, orphan routes, missing loading/error states, unconfirmed destructive actions, and broken navigation edges.

File:line evidence & confidence tiers

Every transition edge carries exact source coordinates (`file:line`), trigger type, confidence score, and real Playwright screen captures.

Interactive local Flow Canvas

Explore Product Map, Story Present lanes, Focus step player, and modal/drawer state frames locally at `127.0.0.1:4317` with zero cloud uploads.

Where cloud analytics & session-replay tools win, and it is not close: PostHog, Amplitude, and FullStory measure real production user drop-off and conversion funnels from live traffic. Code2Flow audits what your codebase actually implements before a single user hits production.

Install once

Install globally via npm or invoke directly with `npx` to audit any frontend or mobile repository on your machine.

npm i -g design-os-code2flow

# Or run directly without global installation
npx design-os-code2flow audit .

First safe use

  1. Run a static AST flow extraction and 11-heuristic UX audit in read-only mode. 
    npx design-os-code2flow audit .
  2. Initialize configuration, `.gitignore`, and agent skills in your target app. 
    code2flow init /path/to/your-app
  3. Scan routes, capture real screenshots, lint flows, and serve the interactive Flow Canvas. 
    code2flow run /path/to/your-app && code2flow serve /path/to/your-app

Examine the structured output before executing live actions. Verified outputs guarantee state integrity.

A practical loop

audit

Statically parses routes, screens, and navigation edges while running the 11-heuristic UX gap detector.

init

Scaffolds `code2flow.config.json`, `code2flow.stories.json`, and AI coding agent skills into the target repo.

run

Boots the dev server, captures Playwright screen & modal states, runs flow lint, and writes an offline bundle.

serve

Launches the local Flow Canvas viewer at `http://127.0.0.1:4317` with Product Map, Present, and Play modes.
