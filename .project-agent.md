## Commands

- cli (dev): `npm run cli -- <command> <target-repo>` (tsx, no build)
- serve (viewer): `npm run cli -- serve <target-repo>` — `127.0.0.1:4317`, strict port
- build: `npm run build` — CLI to `dist/cli` (tsc) + viewer bundle to `out/viewer` (esbuild, fonts inlined); `bin` → `dist/cli/index.js`
- cli (built): `node dist/cli/index.js <command> <target-repo>` / `npx code2flow …` after `npm i` + `npm run build`
- test: `npx vitest run` (each test file works on its own copy of the fixture)
- recall: `npm run recall` (parser vs hand-labelled ground truth)
- lint: `npm run lint` · typecheck: `npx tsc --noEmit`

---

## Key Dependencies

- `@babel/parser` / `@babel/traverse` — AST parsing of the target codebase (routes, triggers, modal/wizard states)
- `playwright` (resolved from the target repo or the tool; uses the installed Chrome, no download) — content-fit screen capture
- `@dagrejs/dagre` — hierarchical auto-layout (bundled into the viewer)
- `esbuild` — viewer bundle; `tsx` / `vitest` — dev and tests

## Binding Rules

- Every coding task: apply the `/es:lazy` ladder — reuse codebase → stdlib → native platform → installed dep → one line → only then minimum code.
- Every feature request: route through `/es:feature-dev` (classify → brainstorm → plan → dev → review).
- 100% local: the CLI and viewer never send target-repo files, graph data, or screenshots to any network service.
- `src/parser/` must not import from `src/viewer/`; both depend only on `src/schema/`.
- Canvas interactions must remain smooth, zoomable, and responsive (SVG canvas, zoom-aware labels).
- Nothing vanishes silently: everything seen but not emitted is a counter in `graph.json`; a re-`scan` keeps the last `snapshot` counters.
- The viewer and every export open with zero network access (fonts inlined at build).
- Every `ActionEdge` carries a `confidence` tier (`high` | `medium` | `low`); low-confidence edges are always visually flagged, never hidden silently.

## Business Context

Code2Flow runs as `npx code2flow <repo>` inside a web project, detects screens (routes, modals, wizard steps, tab states), extracts action triggers, and opens a local infinite canvas showing the end-to-end user journey. A Story Manifest generated from the PO's PRD markdown lets the canvas filter by user story.

Cycle 1 scope (2 weeks): Next.js App Router adapter only. HTML, React Router, and Pages Router adapters are cycle 2.
